# sql-transactions

Transactions and the ACID properties; SQL COMMIT/ROLLBACK and autocommit; how atomicity/durability/
consistency/isolation are achieved (logging, locking, MVCC); the four SQL isolation levels and the
anomalies they permit (dirty/non-repeatable reads, phantoms); lock-based ANSI isolation; and
snapshot isolation with the write-skew anomaly.

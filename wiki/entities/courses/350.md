# ECE/CS 350 — Digital Systems (spring 2026)

Digital systems / computer architecture, spring 2026. **Confirmed ECE/CS 350, cross-listed** —
stated in the course's own project assignment ([[CLAUDE]]). ^[[sources/drive-350-final-project-assignment]]

By far the largest course archive (`uni/spring 2026/350/`, 1,500+ files) ^[[uni/]] — it contains the
custom **processor** (`processor/`, the bulk of the `.v`/`.s`/`.mem` files) and the **final project**
(`project/`), which is [[ece-350-connect4]] (Connect 4 on a 5-stage pipelined FPGA CPU, partner Faiz
Ali). Also midterm cheat sheets (snapshotted, see below), homework, labs. The assignment **prohibits
LLM-generated Verilog** for the deliverable — noted in [[log]]. Concept edges:
[[fsm-state-minimization]], pipelining, hazards.

## Concepts (deep-ingested 2026-07-17)

- [[finite-state-machines]] — Mealy vs Moore, sequence detectors, FSM analysis
- [[fsm-state-minimization]] — state partitioning, row matching, implication charts
- [[boolean-algebra]] — truth tables, SOP/POS, K-maps, Quine–McCluskey minimization
- [[twos-complement-arithmetic]] — signed representations, overflow rules, ranges
- [[binary-multiplication]] — naive shift-add and Booth's / modified Booth's
- [[cmos-logic]] — PUN/PDN synthesis (shared with [[230-semiconductors]])
- [[pipelining-and-hazards]] — structural/data/control hazards, stalling vs forwarding

**Not promoted (candidates):** Hamming codes (error-correcting codes) and combinational
building blocks (mux/demux/encoders) — left as source cards. Verilog tooling is course-specific.

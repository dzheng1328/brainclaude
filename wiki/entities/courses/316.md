## Concepts (ingested 2026-07-17)

- [[relational-algebra]] — the relational model + core/derived operators, monotonicity
- [[functional-dependencies]] — FDs, attribute closure, Armstrong's axioms, keys
- [[database-normalization]] — lossless-join decomposition, BCNF, MVDs, 4NF
- [[entity-relationship-model]] — E/R design and the three ISA translation strategies
- [[database-transactions]] — ACID, isolation levels, snapshot isolation / write skew
- [[sql]] — SELECT-FROM-WHERE, constraints, views, triggers, recursion

semi-structured data / XML–DTD–XPath–XQuery (mid-2 material). Left as source cards for now.

# GoHelpMe

A real-time volunteer-dispatch app that **won 1st place at CUHackIt** (March 2025). ^[[resume drafting/DZ 1.20.26.pdf]]
Real-time dispatch engine in React Native + PostgreSQL using **GIST geospatial indexing** for
proximity-based volunteer matching; an Express.js backend managing a multi-state request lifecycle
with transactional atomic allocation; and a routing microservice over the Google Maps Directions API
with an LRU cache.

**Distinct from [[hacknc]] (Moneta)** — a *different* hackathon project and win: GoHelpMe took
CUHackIt (Clemson, Mar 2025); Moneta was built at HackNC (Oct 2025). Dave has two separate hackathon
projects; do not conflate them, the way [[hw-cnn-accelerator]] and [[ece-350-connect4]] are also kept
separate.

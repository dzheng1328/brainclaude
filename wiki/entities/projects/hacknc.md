# hackNC — Moneta

**Moneta**, an AI-powered financial-literacy learning platform built at HackNC (hackathon).
Full-stack: Next.js 15 frontend + FastAPI/SQLModel/SQLite backend, with lessons generated by
Google Gemini. ^[[hackNC/README.md]]

Features per the README: username/email + password auth with email-based password reset and
database-backed 7-day sessions, guest mode, AI-generated lessons, interactive quizzes
(multiple-choice / fill-in-blank / free-response), an AI "coach" chat, and Duolingo-style
gamification (XP, streaks, progress tracking). Google OAuth is stubbed but not implemented. ^[[hackNC/README.md]]

A **hackathon project** — shipped for the event (last commit 2025-10-12), not actively maintained.
Uses Google Gemini rather than Claude, unlike Dave's other AI builds.
